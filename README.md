# Разбор продаж · помощник продукт-менеджера

Прототип для отбора «ИИкузницы». Продукт-менеджер исследует сигнал о продажах, сверяет источники, уточняет задачу в бэклоге и выбирает проверку эффекта после релиза. Qwen ранжирует свидетельства и предлагает тип проверки. SQLite хранит задачи, решения и журнал фактических вызовов.

## Запуск

Понадобятся Python 3.11+ и локальный сервер `llama.cpp` с моделью Qwen в формате GGUF. Приложение работает на loopback и по умолчанию использует публичный синтетический набор.

```bash
llama-server -m /path/to/model.gguf --host 127.0.0.1 --port 18764 -c 4096 -np 1 --alias pm-local
```

В другом терминале:

```bash
PM_DATA_DIR="$PWD/.demo-data" python3 prototype/app.py
```

Откройте `http://127.0.0.1:18763` и выберите сигнал о самостоятельном счёте. Из разбора можно сохранить задачу, привязать проверку после релиза и просмотреть расход токенов.

Дополнительно можно передать собственную локальную книгу через `PM_EVIDENCE_WORKBOOK`. Для чтения Excel установите `openpyxl`. Лист `Evidence` содержит столбцы `id,type,title,text,source`, лист `Backlog` — `task_id,title,status`. Используйте `demo/evidence.json` как пример состава данных.

В публичной ветке все свидетельства, CRM и результаты A/B синтетические. Прототип поддерживает отдельный тестовый счётчик Метрики и OpenRouter при наличии своих учётных данных. Уведомления представлены предпросмотром. [Сценарий демонстрации](prototype/DEMO.md)

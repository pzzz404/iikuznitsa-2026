# Прототип для отбора «ИИкузницы»

Один участник показывает рабочий путь продукт-менеджера интернет-магазина: заметить сигнал, проверить его по источникам, сохранить задачу в бэклоге и выбрать способ измерения результата. Для отбора нужен непрерывный трёхминутный показ экрана. Пятиминутная живая демонстрация предусмотрена для финала.

Исходные книги организаторов и учётные данные хранятся локально. Отдельная демонстрационная выгрузка иллюстрирует связь заказов с платежами. Все её операции и суммы вымышлены. Результаты этой выгрузки не переносятся на исторические данные магазина.

# Показ прототипа

Публичный набор содержит вымышленные наблюдения, учётные задачи, события и операции. Для исторических данных магазина требуется отдельный закрытый контур.

## Маршрут продукт-менеджера

1. Откройте «Сигналы», выберите вопрос о самостоятельной оплате счёта и нажмите «Исследовать».
2. Посмотрите выбранные Qwen свидетельства, откройте источник и уточните критерий. Сохраните задачу и перезагрузите страницу. Повторное сохранение той же задачи возвращает её номер.
3. Откройте связанную проверку до и после релиза. Подключите синтетические группы, сохраните решение PM и сравните вывод при другом минимальном эффекте. В примере 95% доверительный интервал включает ноль.
4. Смените вопрос на повторную закупку и откройте «Журнал модели». Журнал содержит фактические токены и время ответа. Для локальной модели расходы на железо и электричество учитываются отдельно.
5. Во вкладке «Источники» доступны синтетические CRM и оплаты, статус отдельного тестового счётчика и загрузка исследований. Ежедневные сигналы показаны в предпросмотре.

## Запись

Сначала поднимите локальную модель и приложение по [README](../README.md). Для записи понадобится отдельный пустой каталог базы и снимок синтетических источников из команды `python prototype/jury.py sample /путь/evidence.json`. Передайте путь через `PM_EVIDENCE_FILE` при запуске приложения.

Скрипт записи использует Node.js, Playwright, Chromium, Xvfb и FFmpeg. Озвучка использует локальный Piper и русскую модель для синтеза речи. Переменные `PM_PLAYWRIGHT` и `PM_CHROMIUM` позволяют указать установленные экземпляры.

```bash
npm install --no-save playwright
npx playwright install chromium
mkdir -p video
python prototype/record_audio.py prototype/narration.txt /tmp/pm-demo/narration.wav --cache /путь/к/кешу
xvfb-run -a -s '-screen 0 1440x900x24 -nolisten tcp' node prototype/record.mjs http://127.0.0.1:18763 /tmp/pm-demo video/selection.mp4
```

Скрипт пишет экран непрерывно 180 секунд и сохраняет журнал вызовов в `take.json`. Копию собственного шаблона расчёта можно заполнить командой `python prototype/economics.py template.xlsx calculation.xlsx /tmp/pm-demo/take.json`. Книги, видео и чеки исключены из Git.

## Внешний замер

Для отдельного замера через OpenRouter подготовьте набор командой `python prototype/jury.py synthetic /путь/openrouter.json`. Запустите приложение с `PM_OPENROUTER=1`, отдельными `PM_DATA_DIR` и `PM_EVIDENCE_FILE`. Ключ передаётся локально через `OPENROUTER_API_KEY`. Скрипт `prototype/verify_openrouter.mjs` открывает интерфейс, сохраняет задачу и проверяет привязку списания к вызовам. Калькулятор принимает отчёт этого запуска через `--openrouter`.

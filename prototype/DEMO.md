# Показ прототипа на Beelink

Рабочий интерфейс открывается на Beelink по адресу `http://127.0.0.1:18763`. Службы пользователя `pm-hackathon-local.service` и `pm-hackathon-local-model.service` используют текущий checkout. История магазина читается из Excel локально. Владелец работает в своей базе `~/.local/share/pm-hackathon`.

Визуальные параметры сверены в Chromium с [официальным сайтом Softline](https://softline.ru/) при 1439 × 812 CSS-пикселях. У сайта Manrope, начертание 400 у заголовков, 500 у навигации и кнопок и 600 у бордовых ссылок. Основная кнопка на главной использует фон #A50F2D, высоту 50 px и радиус около 100 px. Вторичная кнопка той же формы на сайте полупрозрачная поверх фото. В рабочем интерфейсе её аналог светло-серый и располагается на фоне #F2F5F8. Поля и служебные карточки имеют скругление 4 px. Шрифт поставляется локально под SIL OFL.

## Воронка покупок

Первый экран сравнивает средние недельные индексы самостоятельных заказов из v17 и показывает, какие этапы связываются счётчиками. Выберите семейство, два окна одинаковой длины, устройство или роль покупателя. Визитные доли через изменение входа 29 сентября не сравниваются. Если полей устройства или роли нет, соответствующая доля отсутствует.

В показе для жюри доступны два шестинедельных индекса Kaspersky и Astra, а также согласованные счётчики первого перехода Astra за две указанные октябрьские недели. Снимок формируется командой `prototype/jury.py funnel` в отдельный файл демоданных. Для открытых доступов применяется действующий режим с приглашением.

На красной карточке заказов Kaspersky нажмите «Открыть отклонение». В первичной сверке видны Astra, даты релизов и T-08. Кнопка «Проверить связь с релизом конфигуратора» ставит выбранный срез в очередь локальной Qwen. Пока модель работает, можно открыть другой раздел. По завершении PM Radar покажет уведомление со ссылкой на тот же разбор.

PM может связать проверку с T-08, утвердить отдельную задачу или отложить с причиной. Вместе с решением сохраняются источники и условие повторной проверки. В «Проверках» исторические исходы остаются неизвестными до сверки действий и событий. A/B доступен для сценариев изменения покупательского опыта.

«Выбор лицензии» ведёт к проверке прохождения Astra и покрытию вариантов Kaspersky. «Возможности роста» содержит черновик проверки повторной покупки. «Каталог» показывает также товары с качественными материалами, для которых в выгрузке нет истории заказов.

## Локальные сигналы

1. В «Сигналах» выберите самостоятельную покупку по счёту и нажмите «Исследовать». Откройте исследование со временем прохождения или другой источник, который выбрала Qwen.
2. Уточните критерий, сохраните задачу, повторите сохранение из того же разбора и перезагрузите страницу. Должна остаться одна задача с тем же номером.
3. Откройте связанный план. До релиза нужен базовый уровень. Включите синтетическую выборку и сохраните решение PM. При значениях из примера основная доля меняется на +2,7 п. п., 95% интервал от −3,3 до +8,6 п. п. Вывод «Данных недостаточно». Для порога 9 п. п. результат меняется на «Минимальный эффект не достигнут».
4. Для альтернативы выберите повторные закупки. Результат и источники меняются. В «Журнале модели» видны фактические токены и длительность каждого вызова. В «Источниках» доступны отдельные вкладки для истории, синтетических оплат и тестового счётчика.

Для записи дубля выберите новый пустой каталог базы, создайте демовыдержки при помощи `prototype/jury.py sample` и передайте путь к файлу через `PM_EVIDENCE_FILE`. Запустите `prototype/app.py --port 18775` с этой переменной и отдельным `PM_DATA_DIR`. Для записи понадобятся Chromium, Xvfb, FFmpeg и Piper из кеша участка работы.

```bash
python prototype/record_audio.py prototype/narration.txt /tmp/pm-hackathon-work/narration.wav
xvfb-run -a -s '-screen 0 1440x900x24 -nolisten tcp' node prototype/record.mjs http://127.0.0.1:18775 /tmp/pm-hackathon-work video/new-take.mp4
```

Один процесс FFmpeg пишет экран 180 секунд. Отдельная звуковая дорожка — русская синтетическая озвучка. Скрипт сохраняет возвращённые браузеру замеры и данные задачи в `take.json` в рабочем каталоге. Этот файл позволяет обновить копию калькулятора через `prototype/economics.py`. Плата за токены локальной модели по шаблону 0 ₽. Мощность, электричество и амортизация сервера отдельно, замера нет.

## OpenRouter

Для отдельного сквозного замера настроен `qwen/qwen3-32b`. Ключ читается из `~/.config/pm-hackathon/openrouter.key` с правами `600` или из `OPENROUTER_API_KEY`. Запустите `prototype/app.py --port 18773` с `PM_OPENROUTER=1`, отдельным `PM_DATA_DIR` и `PM_EVIDENCE_FILE`, созданным командой `prototype/jury.py synthetic`. Стенд принимает один заранее заданный вопрос и использует вымышленные примеры из отдельного набора.

```bash
node prototype/verify_openrouter.mjs http://127.0.0.1:18773 ~/.local/share/pm-hackathon-openrouter/measurement.json
python prototype/economics.py calculator.xlsx calculator-prototype.xlsx /tmp/pm-hackathon-work/take.json --openrouter ~/.local/share/pm-hackathon-openrouter/measurement.json
```

Скрипт ведёт запрос через браузер, открывает источник, уточняет критерий и находит сохранённую задачу после перезагрузки. Таблица суммирует списания в USD по связанным вызовам. Первичный источник списания — `usage.cost`, резервный — `generation.total_cost`. Для рублёвого пересчёта служит подтверждённый курс в I3. Токены разработки Codex ведутся вне этого расчёта.

## Доступ жюри

Защищённая ссылка лежит в `~/.local/share/pm-hackathon-jury/invitation.txt`. Funnel принимает HTTPS на 8443. В стенде общий для приглашённых демобэклог, отдельная модель и не более 16 запусков модели в сутки по UTC. Приглашение действует до 2 декабря 2026 в 21:00 МСК. Срок выбран с запасом после питчей 1 декабря. Таймер выключает только стенд жюри и его маршрут.

Владелец может отозвать одно приглашение с помощью `prototype/jury.py revoke`, передав файл реестра и файл приглашения. Для досрочного выключения стенда запустите `systemctl --user start pm-hackathon-jury-expiry.service`.

## Ограничения

- Тестовый счётчик Яндекс.Метрики требует ID и OAuth-токен с правом чтения. Служба локального приложения читает `METRIKA_COUNTER_ID` и `METRIKA_OAUTH_TOKEN` из `~/.config/pm-hackathon/metrika.env`.
- Проверены 11 исходных свидетельств, 8 исходных задач и импорт 1000 синтетических записей в Chromium. Нагрузку 1000 реальных интервью и длительную работу с несколькими запросами ежедневно предстоит проверить.
- Доставка ежедневных сигналов показана как предпросмотр. Исторический срез ожидает реальные результаты после релиза. Результат A/B и набор CRM синтетические.
